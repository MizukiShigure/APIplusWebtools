# 可编辑提示词详情面板设计

## 目标

把任务表格中的“查看全部”提示词面板从只读预览升级为统一的提示词编辑面板：

- 未锁定任务可以在面板内编辑提示词，并实时保存到对应任务行。
- 排队中、生成中和部分处理中任务保持只读。
- 多模态生视频任务可以点击或拖动参考素材，在提示词指定位置插入对应的 `@N`。
- 编辑过程不重新渲染整个表格，不改变用户当前滚动位置。

## 适用范围

可编辑提示词面板适用于当前所有使用 `renderPromptCell` 和“查看全部”入口的任务页：

- 生图
- 图文生视频
- 动作模仿
- 数字人
- 多模态生视频
- Vidu 参考生视频

素材 `@N` 插入交互只在多模态生视频页面启用。其他页面继续展示对应行参考素材，但素材卡不提供 `@N` 插入能力。

## 交互设计

### 打开面板

点击任意任务行的“查看全部”后，打开现有白色详情面板并载入：

- 当前行完整提示词
- 当前行参考素材
- 当前任务是否处于锁定状态
- 当前任务类型

空提示词使用 textarea 的占位文案表示，不把“无 Prompt”写入真实字段。

### 编辑与保存

未锁定任务的 textarea 可编辑。每次输入时：

1. 立即更新内存中的 `row.prompt`。
2. 标记已完成但内容被修改的任务为“有未提交修改”。
3. 同步原表格行内的紧凑提示词 textarea。
4. 使用短延迟合并连续输入后，调用该页面原有持久化函数。

textarea 失焦、关闭面板和按 Escape 关闭时必须立即刷新尚未落盘的修改，避免最后一次输入丢失。

保存过程中不调用全页 `render()`，不改变表格滚动位置，也不关闭面板。

### 锁定规则

沿用各任务页现有的行锁定函数，不建立第二套状态判断：

- `queued`
- `running`
- 仍有未完成任务的 `partial`
- 其他由现有锁定函数判定为不可编辑的状态

锁定时 textarea 为只读，素材卡不可点击插入或拖动。复制提示词仍然可用。

如果面板打开后任务状态变为锁定，每次编辑、点击素材或拖放素材前重新检查锁定状态；检测到锁定后停止写入并把面板切换为只读。

### 多模态素材插入

多模态参考素材按行内现有顺序显示，并使用 `@1`、`@2`、`@3` 等标签。

点击素材卡：

- 在 textarea 当前光标位置插入对应 `@N`。
- 如果文本被选中，用 `@N` 替换选中内容。
- 插入后光标停留在 `@N` 后面，textarea 保持焦点。

拖动素材卡到 textarea：

- 使用浏览器提供的指针坐标定位文本插入点。
- 在鼠标放开位置插入对应 `@N`。
- 浏览器不支持按坐标获取 textarea 光标时，回退到 textarea 最近一次选区位置。
- 插入后立即执行与普通输入相同的保存流程。

只插入引用文本，不复制、移动或重排素材，不重新上传文件，也不生成新的 URL。

## 组件边界

### 面板上下文

`openPromptDetailPanel` 接收统一上下文，至少包含：

- `row`：当前任务行
- `refs`：当前展示的参考素材
- `type`：任务类型
- `isLocked()`：复用当前页面行锁定函数
- `updatePrompt(value)`：更新行数据、脏状态并持久化

面板只负责编辑和素材引用交互，不直接判断各页面的存储键或队列状态。

### 提示词插入工具

建立独立的纯函数处理：

- 原文本
- 选区开始位置
- 选区结束位置
- 插入 token

返回更新后的文本和新光标位置。点击插入与拖放插入共用该函数，避免两条路径产生不同结果。

### 页面绑定

各任务页在绑定“查看全部”按钮时提供自己的上下文：

- 对应锁定函数
- 对应字段更新函数
- `redraw = false` 或等价的不重绘保存方式

## 数据与状态

- 不新增提示词副本，唯一数据源仍为对应的 `row.prompt`。
- 不改变任务结果、任务 ID、参考素材顺序或上传缓存。
- 已完成任务首次修改时调用现有脏状态逻辑，保留旧结果直到重新提交。
- 关闭并重新打开面板时读取最新 `row.prompt`，不依赖面板内的旧缓存。

## 错误与兼容处理

- 无法计算拖放文本位置时，使用最近一次光标位置。
- 剪贴板复制失败沿用现有复制提示词错误处理。
- 页面持久化失败不清空内存中的编辑内容。
- 面板被锁定时忽略编辑与素材插入事件，不修改任务数据。
- 无参考素材时继续显示空状态，不影响提示词编辑。

## 测试方案

### 自动测试

扩展提示词详情面板测试，覆盖：

- textarea 在未锁定状态下可编辑，锁定状态下只读。
- 编辑使用页面提供的更新回调并禁止全页重绘。
- 空提示词使用 placeholder，不写入“无 Prompt”。
- 点击多模态素材在当前选区插入 `@N`。
- 拖放多模态素材使用指针位置，失败时回退到当前选区。
- 素材插入后触发与键盘输入相同的保存流程。
- 锁定行不能通过详情面板修改提示词。
- 复制按钮读取当前 textarea 内容。

### 回归测试

运行项目完整 `npm test`，重点确认：

- 任务行锁定规则不变。
- 已完成行修改后仍显示“有未提交修改”。
- 多模态原有行内 `@N` 和请求打包规则不变。
- 各任务页原有实时输入、复制、清空和粘贴提示词功能不受影响。

## 验收标准

1. 未运行任务在“查看全部”面板中编辑后，关闭并重新打开仍显示最新内容。
2. 编辑时表格不跳动，滚动位置不改变。
3. 已完成任务被编辑后显示“有未提交修改”。
4. 运行中任务的详情面板只读，复制提示词仍可用。
5. 多模态素材点击后在当前光标处插入正确的 `@N`。
6. 多模态素材拖到提示词某一位置后，在该位置插入正确的 `@N`。
7. 素材插入不会改变素材顺序、缓存记录或上传 URL。
